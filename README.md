# PPUnlock-Offline v3.0.3（ILCE-6100 Ver.1.00）

完全离线的 Picture Profile 解锁工具，免联网、免服务码、无需安装 Python。

> ⚠️ **测试版风险提示**：本工具会改写相机内文件，存在相机无法开机（变砖）的可能。请谨慎使用，后果自负；仅供学习研究。仅支持 **Sony ILCE-6100 固件 Ver.1.00、Windows**。

## 文件清单

| 文件 | 说明 |
|---|---|
| `PPUnlock-Offline-v3.0.3.exe` | 主程序（单文件，Nuitka 构建） |
| `SHA256SUMS.txt` | 主程序哈希，用于校验完整性 |

## 使用前准备

1. 相机菜单（Setup → 大约/版本）确认机型 A6100、固件 Ver.1.00，电量 > 50%。
2. 在 Fn 菜单或自定义快捷键中加入「美肤效果」（找不到可刷完后再设置）。
3. 用稳定数据线连接电脑，相机开机并进入 USB 连接模式。
4. 若提示缺驱动，从 <https://zadig.akeo.ie/> 下载 Zadig：Options → List All Devices，只选中当前 Sony 相机，目标驱动选 WinUSB 安装，不要改动电脑其他设备。
5. 可先运行 `PPUnlock-Offline-v3.0.3.exe --selftest` 做只读自检（不写相机）。

## 使用

1. 双击 exe，选「1. 写入 Picture Profile 解锁」或「2. 恢复相机原状态」。
2. 工具先只读核对 CC、viewUnified2、启动脚本与 MD5，任一不符立即停止，不要强行继续。
3. 每个需要写入的文件单独询问，输入大写 `YES` 才执行；期间不要拔线、不要关机。写入约 1–2 分钟，相机应用崩溃一次并自动恢复属预期。
4. 结束后断开 USB、关机、取电池静置 10 秒再装回开机；在 Fn 的「美肤效果」位置和主菜单颜色页检查 PP1–10，拍一张 PP1 回放，并反复开关机 2–3 次确认设置保留。

## 撤回（恢复原状态）

选「2. 恢复相机原状态」：先只读核对状态，删除本工具添加的启动入口，再按 MD5 门禁逐项还原本工具改动的文件，每项需输入 YES。恢复依赖相机内原始 viewUnified2 备份；备份缺失或状态未知时工具会停止，不会写入。

## 常见问题与应急

- **找不到相机**：检查开机、数据线、USB 模式，用 Zadig 重绑 WinUSB 后重插。
- **MD5 / 版本不匹配**：固件不是 1.00 或已被改过，立即停止，不可跳过。
- **异常或反复重启**：取下电池静置 10 秒再装回开机；仍异常用「恢复」还原 CC。
- **完全不开机**：本工具不含救砖/JTAG，需另行通过官方固件恢复手段处理；操作前务必电量充足、全程不拔线。

## 完整性校验

```powershell
certutil -hashfile PPUnlock-Offline-v3.0.3.exe SHA256
```

应与 `SHA256SUMS.txt` 中的值一致。
