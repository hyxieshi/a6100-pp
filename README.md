# PPUnlock-Offline v3.0.3（ILCE-6100 Ver.1.00）

完全离线的 Picture Profile 解锁工具，免联网、免服务码、无需安装 Python，单文件双击即用。

> ⚠️ **测试版风险提示**：本工具会改写相机内文件，存在相机无法开机（变砖）的可能。请谨慎使用，后果自负；仅供学习研究。仅支持 **Sony ILCE-6100 固件 Ver.1.00、Windows**，其他机型/固件版本会被 MD5 门禁直接拦截。

## 文件清单

| 文件 | 说明 |
|---|---|
| `PPUnlock-Offline-v3.0.3.exe` | 主程序（单文件，Nuitka 构建，内置加密知识） |
| `SHA256SUMS.txt` | 主程序哈希，用于校验文件未被篡改 |

## 一、使用前准备

1. **确认机型与固件**：相机开机 → 菜单 Setup → 「大约/版本」，确认型号为 ILCE-6100、固件 Ver.1.00。版本不符不要继续。
2. **电量充足**：电池电量 > 50%，最好充满；全程不要中途换电池或关机。
3. **把「美肤效果」放进 Fn**：在 Fn 菜单或自定义快捷键里加入「美肤效果」（这是解锁后 Picture Profile 的显示位置；现在找不到也可刷完再设）。
4. **连接相机**：用质量稳定的数据线（不要用只能充电的线）把相机接到电脑，相机开机并切到 USB 连接模式。
5. **驱动（仅在提示缺驱动时）**：从 <https://zadig.akeo.ie/> 下载 Zadig → Options → List All Devices → 只选中当前连接的 Sony 相机 → 目标驱动选 WinUSB → Install。不要选择电脑上的鼠标、键盘等其他设备，装错会导致其他硬件失灵。
6. **先跑只读自检**：命令行进入本目录执行，不写相机：

```powershell
PPUnlock-Offline-v3.0.3.exe --selftest   # 资源/知识/传输层自检，退出码 0 = 通过
PPUnlock-Offline-v3.0.3.exe --offline    # 只检查离线资料与构建计划
PPUnlock-Offline-v3.0.3.exe --help       # 帮助
```

## 二、写入操作（解锁 PP）

1. 双击 `PPUnlock-Offline-v3.0.3.exe`，菜单选「1. 写入 Picture Profile 解锁」。
2. 工具先**只读**核对 CC、viewUnified2、启动脚本的 MD5 基线；任一不符会立即停止并说明原因，不要想办法跳过。
3. 每个需要写入的文件都会单独弹出确认，输入**大写 `YES`** 才执行，输其他任意键即取消。
4. 写入约 1–2 分钟（分段传输），**期间不要拔线、不要关机、不要最小化后乱动**；写入瞬间相机应用崩溃一次并自动恢复，属于预期现象。
5. 工具显示“完成”只代表写入阶段结束，是否成功以实机验证为准。

## 三、写完后的实机验证

1. 断开 USB → 关机 → 取下电池静置 10 秒 → 装回开机（彻底断电重启）。
2. 按 Fn，原「美肤效果」位置应显示为 Picture Profile，进入后 PP1–PP10 可选可设。
3. 主菜单颜色页在开机约十几秒（poke 落笔）后应出现 Picture Profile，其他菜单功能正常。
4. 选 PP1 拍一张 → 回放确认生效 → 再关机开机，设置仍在；反复开关机 2–3 次确认稳定。

## 四、撤回（恢复相机原状态）

菜单选「2. 恢复相机原状态」：工具先只读核对 CC、viewUnified2、原始备份和启动脚本标记，状态超出已知 MD5 或标记重复时停止。随后逐项删除本工具添加的启动入口、还原本工具改动的文件，每项都需单独输入 YES，写完重新连接并复核 MD5。

- 恢复依赖相机内原始 viewUnified2 备份；备份缺失或状态未知时工具会停止，不会强行写入。
- 恢复流程尚未在新机上完整实测，不能保证 100% 还原。

## 五、常见问题与应急

| 现象 | 处理 |
|---|---|
| 找不到相机 / ABORT: no MSC | 确认相机已开机、数据线可用、处于 USB 模式；按 Zadig 重绑 WinUSB 后重插 |
| baseline / MD5 mismatch | 固件不是 1.00 或已被改过，立即停止，不可强行继续 |
| senser not enumerated | 对应设备未绑 WinUSB，重插相机后重试 |
| 应用反复重启 / 操作后异常 | 取下电池静置 10 秒再装回开机；仍异常用「恢复」还原 CC |
| 开机先是美肤、稍后变 PP | 正常，poke 在开机延迟后才落笔 |
| 完全不开机 | 本工具不含救砖/JTAG，需另行通过官方固件恢复手段处理；操作前务必电量充足、全程不拔线 |

## 六、完整性校验

下载后先核对哈希，防止文件被替换：

```powershell
certutil -hashfile PPUnlock-Offline-v3.0.3.exe SHA256
```

输出应与 `SHA256SUMS.txt` 中的 `038d0c508aa7a92bd54a142d77120962c1d42a00529733f7b74586016babe0d2` 一致。
